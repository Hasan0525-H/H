# H

**HAI** is an Android AI workspace focused on conversation, software projects, GitHub workflows, voice, media and automated tasks.

## Identity
- App name: **H**
- Product identity: **HAI**
- Package compatibility: `com.haiom.app` is intentionally retained so H can upgrade compatible legacy installs.
- Visual identity: rebuilt for H/HAI.

## Core capabilities
- AI chat with rich responses and generated media
- Voice input
- GitHub account and repository workflows
- Programming-agent execution
- Automatic task queue
- In-app update checks
- Secure local credential storage

## Build
Android 8+ (API 26+). CI runs unit tests, lint and a debug APK build.

> Internal package/storage identifiers may retain legacy-compatible names solely for Android upgrade and data compatibility; they are not part of the HAI product identity.
